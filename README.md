# AgriTech - Google Solution Challenge Project

## Overview
This project is our Google Solution Challenge project that is mainly designed to help small farmers. Our platform provides essential agricultural support and resources to empower farmers with the tools and information they need to succeed.

## Key Features

### 🌤️ Weather Information
- Know weather information to help farmers plan their agricultural activities
- Real-time weather updates and forecasts
- Weather-based farming recommendations

### 🌾 Crop Management
- Farmers can sell crops through our platform
- Marketplace functionality for agricultural products
- Direct farmer-to-consumer connections

### 🧪 Fertilizer Services
- Farmers can buy fertilizer through our platform
- Quality fertilizer recommendations
- Cost-effective fertilizer solutions

### 🏛️ Government Schemes
- Information about government schemes related to farmers
- Access to agricultural subsidies and support programs
- Guidance on eligibility and application processes
